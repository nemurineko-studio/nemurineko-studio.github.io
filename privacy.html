MindLog プライバシーポリシー

ホーム 使い方ガイド プライバシーポリシー 利用規約

最終更新日: 2026年10月5日

MindLog（以下「本アプリ」）は、個人開発スタジオ Nemurineko Studio（連絡先: checkup850@gmail.com、以下「開発者」）が提供するAI日記アプリです。 本ポリシーは、本アプリが取り扱う情報とその利用目的を説明するものです。

1. 取得する情報

ユーザーが入力する情報

  • 日記の本文・気分タグ・写真: 本アプリの中核機能である日記の記録のために取得します
  • アカウント情報（メールアドレス）: アカウントの識別のために取得します
  • 氏名: 「Appleでサインイン」を利用した場合にのみ、Appleのサインイン画面で共有される氏名を受け取ります（共有する氏名は同画面で編集できます）。アプリ内でのアカウント表示のために利用します

自動的に取得される情報

  • 購入情報: サブスクリプションの購入状態を管理するため、決済基盤（RevenueCatおよびアプリを入手したストア）を通じて取得します。クレジットカード番号等の決済情報を開発者が直接取得することはありません
  • ユーザーID: アカウント（登録なしで利用する場合を含む）ごとに自動で発行される識別子です。保存したデータの区別、AI機能の利用回数の管理、購入状態の管理（RevenueCatへの連携）のために利用します
  • 利用状況データ: 本アプリの改善のため、Google Analytics for Firebase を通じて、アプリ内の操作に関するイベント（例: 初回起動、画面の表示、最初の日記の保存、アカウント作成、購入画面の表示、購入の開始・完了）、アプリのインストールごとに発行される識別子、OSが開発元ごとに端末へ割り当てる識別子（広告識別子ではありません）、端末の機種・OSのバージョン・言語、IPアドレスをもとに推定されるおおよその地域（端末の位置情報機能は使用しません）などの情報を取得します。日記の本文や気分などの内容は含まれず、ユーザーIDやメールアドレスとも結び付けません。広告の配信やトラッキングには利用せず、広告識別子も取得しません

登録なしで利用する場合（ゲスト利用）

  • アカウントを登録せずに利用を開始した場合、メールアドレスや氏名は取得しません。上記のユーザーIDが自動で発行され、日記データ（本文・気分タグ・写真）は、登録した場合と同じくGoogle Firebaseのサーバーに保存されます（端末内だけに保存されるわけではありません）
  • あとからアカウントを作成すると、日記はそのまま引き継がれます
  • 登録しないまま、サインアウトした場合・別のアカウントにサインインした場合・アプリの削除や機種変更をした場合は、そのデータに再びアクセスできなくなることがあります。この場合、データはサーバー上に残りますが、どなたのデータかを開発者が確認できないため、メールでの個別の削除依頼にはお応えできません。削除をご希望の場合は、その前にアプリ内の「設定 → アカウントを削除」を行ってください

2. 情報の保存場所

  • 日記データ（本文・気分タグ・写真）は、機能提供のためGoogle Firebase（Google Cloud Platform）に保存されます
  • 端末がオフラインの間は端末内に一時保存され、接続時に同期されます

3. AI機能における情報の取り扱い

AIフィードバック・週次/月次/年間レポート等のAI機能を利用する場合、対象となる日記テキストが、開発者のサーバー（Firebase）を経由して米国Anthropic社のAI「Claude」のAPIに送信されます。

  • 送信は、アプリ内で送信内容の説明を表示した上で、ユーザーが明示的に同意した場合にのみ行われます。 同意は初回のAI機能利用時に確認し、アプリの「設定」からいつでも変更（撤回）できます
  • 送信されるのは、機能の実行に必要な日記テキスト（本文・気分タグ・返答の参考にする過去の日記の一部）のみです
  • Anthropic社のAPIは、送信されたデータをモデルの学習に使用しません（Anthropic社の商用API利用規約に基づく）
  • 同意しない場合、またはAI機能を利用しない場合、日記データが外部のAIサービスに送信されることはありません。その場合もAI以外の機能はすべて利用できます

4. 利用目的

  1. 日記の記録・表示・同期などの本アプリの機能提供
  2. AIフィードバック・レポート等のAI機能の提供
  3. サブスクリプションの購入状態の管理
  4. お問い合わせへの対応
  5. 利用状況の分析による本アプリの改善

5. 第三者提供

法令に基づく場合を除き、ユーザーの同意なく個人情報を第三者に提供することはありません。 前述のFirebase（Google。Google Analytics for Firebase を含みます）、Claude API（Anthropic）、RevenueCatは、機能提供および利用状況の分析に必要な範囲での処理の委託先です。 これらの事業者は、米国など日本国外のサーバーで情報を処理する場合があります。

Google Analytics for Firebase によるデータの収集・処理については、Googleの 「Google のサービスを使用するサイトやアプリから収集した情報の Google による使用」 をご覧ください。

6. データの保存期間と削除

  • サーバーに保存されたデータは、ユーザーがアカウントを削除するまで保存されます（登録なしで利用している場合も同じです）。アプリをアンインストールしただけでは、サーバー上のデータは削除されません
  • アプリ内の「設定 → アカウントを削除」から、アカウントと日記データ（写真を含む）をすべて削除できます。登録なしで利用している場合も、同じ画面から削除できます
  • 削除のご依頼は下記メールアドレスでも受け付けます。本人確認のうえ、登録データを削除します。登録なしで利用していた場合は、開発者側でご本人のデータを特定できないため、メールでのご依頼には対応できません。必ずアプリ内から削除してください
  • 利用状況データ（ユーザーIDとは結び付けていません）と、ストアおよびRevenueCatが保持する購入の記録は、アカウントを削除しても直ちには消去されず、各事業者の定める期間保持されます

7. 通知

リマインダー通知は、ユーザーが設定した場合にのみ、端末のローカル通知として送信されます。通知のために外部にデータが送信されることはありません。

8. 生体認証

アプリロック機能で使用する生体認証（Face ID / 指紋認証）は端末のOS機能を利用するものであり、生体情報が本アプリや開発者に送信されることはありません。

本ポリシーを変更する場合は、アプリ内または本ページでお知らせします。
